# 方案甲 确认简报（U11）


## 取值确认

| 项 | 取值 |
| --- | --- |
| 击杀金币（英雄/塔击杀） | **归零（0）**，非 10% |
| 开局金币 | **400**（原 300；击杀金归零后早期保底） |
| 目标用时表 | 沿用原 `STAGE_TIME_LIMIT`；**第 2 关 = 第 1 关 ×2**（仅作速度目标，不失败） |
| 超时失败 | **移除**；计时改速度参考（已用时间 + 评级），暂停/奖励面板仍冻结 |
| 过关金币公式 | `clear_gold = base_by_stage_and_diff * clamp(target_time / max(elapsed, 1), 0.35, 1.6)` |
| base 取值 | `CLEAR_GOLD_BASE=180` × 关卡时代倍率 × 难度系数（easy 1.15 / normal 1.0 / hard 0.9） |
| 击杀积分 | × **0.25**（弱化磨兵）；塔击杀仍不加击杀分 |
| 过关积分 | 关卡分 + 速度分，累加进本局 `kill_score`（排行榜仍用总分，SaveManager 兼容） |
| 悬赏令 | 改为「立即金币 + 30 秒内过关金币 +25%」，不再按击杀给金 |
| 战利品增益 | 改为「本轮过关金币 +30%」 |
| 局中消耗 | 重排/清台/刷新奖励 **保留不变** |
| 清空按钮 | **不删**（U12） |

## 范围外

- 不改战斗手感、不出美术大改、不外发密钥

## 计算公式

- 英雄生命 = 定位基础生命 × 时代倍率；英雄攻击 = 定位基础攻击 × 时代倍率。
- 射程 / 移速 / 攻击间隔 / 击杀积分只看定位，不随时代变化。
- 敌方单位 = 上述数值 × 难度倍率（生命与攻击都乘）。
- 防御塔生命 = 1800 × 时代倍率；塔伤害 = 30 × 时代倍率，间隔 1.1 秒，射程 420。
- 防御塔击杀敌人给金币但不给击杀积分，因此时代进阶只由英雄击杀推进。
